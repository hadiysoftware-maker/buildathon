The problem and our solution

Campus 2035 asks: what does a school look like in 10 years?

Today a school day runs on paper registers, shared passwords, scattered files and manual lookups. EduCore is our answer: a campus where identity, timetable, study material and AI help are one connected system.

The problem

  • Slow, insecure sign-in: shared logins and forgotten passwords waste lesson time and cannot prove who is who.
  • Scattered information: timetables, notes and notices live in chats, paper and different apps.
  • Admin overload: counting students, tracking cards and workloads is done by hand.
  • Unsafe AI: general chatbots see no school data, and student chats are not private.
  • Cost: AI used for every question is expensive for schools.

Our solution

  • Smart ID card: tap or scan a card; a username and password is the backup for teachers and students.
  • One portal per role (Admin, Teacher, Student) showing only what that role may see.
  • Live timetable and Library: teachers upload, students read, files stay private on R2.
  • Nova, the AI copilot: answers with charts, cards and timelines from real data.
  • Chats encrypted per user: only the owner can read their history.
  • Zero-token routing: everyday data questions skip the AI and cost nothing.

Security by design

  • Argon2id passwords, lockout after 5 failures, rate limits
  • Smart ID secrets shown once, stored as HMAC hashes
  • Permissions re-checked on the server for every page and API
  • AES-256-GCM chat encryption with a key per user
  • Private R2 bucket; files open only through signed links

AI that is cheap and agentic

  • Router answers common questions with no model call
  • Open-ended help uses a free-tier model chain with fallback
  • Tools run with the user's own role, never a model-chosen identity
  • Visual answers: donut, bar, student and teacher cards, timeline, summary, page links

Built to deploy

Next.js 16 on Vercel, MySQL through Prisma, Cloudflare R2 for files, Groq for language. Responsive from phones to wide screens; 38 automated tests; code at github.com/hadiysoftware-maker/buildathon.

Honest status

Verified: role access, per-user chat privacy, Smart ID and password sign-in, R2 upload flow (API), AI visuals. Next steps: let the AI read file contents, guardian portal, attendance marking by teachers.
